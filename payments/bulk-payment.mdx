---
title: "Proposing Multiple Payments"
description: "Request payments for multiple recipients at once"
---

You can create bulk payment requests to pay multiple recipients at once instead of creating separate [single-payment requests](/payments/single-payment).

This is especially useful when you need to pay a large number of recipients with the same token, as it allows you to request all payments in a single request, saving you from having to create them separately.

<Warning>
  Payment requests can only be created by team members with the [Requestor](/governance/members-and-roles#requestor) role, and they require approval from team members with the [Finance](/governance/members-and-roles#finance) role before they can be executed.
</Warning>

---

## Bulk Payment Request

Navigate to the **`Payments`** section in the left sidebar, then click **`Bulk Payments`**.

![Bulk payment button](/assets/docs/payments/bulk-payment-button.webp)

Specify which token you want to use—all recipients will be paid in the same token. Then, manually enter the payment details for each recipient or upload a `.csv` file containing the information.

![Bulk payment request form](/assets/docs/payments/bulk-payment-request.webp)

<br />

<Accordion title="Bulk Payment Format">
  The expected format is a list of recipients with their wallet addresses and payment amounts. For example, to pay `10.50 USDC` to `alice.near` and `21.34 USDC` to `bob.near`, enter the following data in the **`Provide Data`** section:

  ```
  alice.near, 10.50
  bob.near, 21.34
  ```

  Alternatively, download the <a href="https://raw.githubusercontent.com/NEAR-DevHub/trezu-docs/refs/heads/main/assets/files/bulk-payment-template.csv" onClick={(e) => { e.preventDefault(); fetch(e.currentTarget.href).then(r => r.blob()).then(b => { const a = document.createElement('a'); a.href = URL.createObjectURL(b); a.download = 'bulk-payment-template.csv'; a.click(); URL.revokeObjectURL(a.href); }); }}>template</a>, fill in the payment details, and upload the file in the **`Upload File`** section.
</Accordion>

## Reviewing the Request

Review the bulk payment request before submitting it. You can add a comment to provide more context to the approvers.

![Bulk payment review](/assets/docs/payments/bulk-payment-review.webp)

<Tip>
  After the bulk payment is approved and executed, you can generate a [receipt](/payments/handling-requests).
</Tip>


<Warning>
  Verify the blockchain and wallet addresses before submitting the request, as payments are irreversible.
</Warning>

---

## What's Next?

After submitting the payment request, it will be ready for team members with the [Finance](/governance/members-and-roles#finance) role to review and vote on.
